# Blocky Math Runner

A 3D blocky educational math running game for computer, tablet, and phone.

## Publish to GitHub Pages

1. Create a new repository on GitHub (for example, `blocky-math-runner`).
2. Upload `index.html` and `.nojekyll` to the root of the `main` branch.
3. Open **Settings → Pages**, set **Source** to **Deploy from a branch**, select `main` / `/ (root)`, and click **Save**.
4. Your game will be live at `https://<your-username>.github.io/<repo-name>/`.
